# Metaworld-Learning
A personal repo used to learn RL using Metaworld. The project is split into three sections meta learning, multi-task learning, and inverse reinforcment learning.

## Meta Learning
The meta learning sections contains an agent trained using [MAML](https://arxiv.org/pdf/1703.03400) on Metaworld's ML1 and ML10 environments.
